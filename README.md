This repo contains the code and data used to create a collared pika (*Ochotona collaris*) acoustic recognizer and to conduct associated analyses.

### **scripts folder**  ####
Contains scripts for: i) creating and evaluating a collared pika recognizer; ii) modelling the impact of call quality on recognizer performance; iii) plotting diurnal pika calling activity; and iv) clustering calls by age class and population.

### **recognizer_outputs folder**  ####
Contains large `.RData` files with recognizer predictions on multiple days' worth of data from study sites. Also contains files produced by the recognizer during training and, most importantly, the final recognizer model used in our analyses.

### **data folder**  ####
Contains all other data except for training/validation/testing audio recordings due to file size limits.

### **figures folder**  ####
Contains figures from all analyses.

*Note that the study site Nàday Gän (NG) may be referred to as Mt. Decoeli (MD) in the data and code.
